# あそびかた

ホームの「あそびかた」に何を書くかの基準。細かいルール（時間帯ごとのポイント、バッジの条件、レベル表）は図鑑で見せるので、ここには書かない。

## ゲーム性はどこにあるか

| | 何をする | 遊びどころ |
|---|---|---|
| 毎日 | 毎朝の投稿で「出社した」ボタンを押す | ポイントがたまり、かたがきが上がる（成長） |
| 工夫 | 早く来る・続けて来る、アイテムを選ぶ | 同じ出社でもポイントが変わる（選択） |
| みんな | 今週の目標をみんなで達成する | 自分の出社がみんなのボーナスになる（協力） |
| 長く | Lv5 から転生する、1400pt に届く | いつ転生するかを決める。でんせつのしるしを集める（長期の目標） |
| 発見 | 図鑑でバッジの条件を推理する | 隠れたバッジを見つける（収集） |

中心は「毎朝ボタンを押すと、でんせつのかいしゃいんに近づく」こと。ほかはすべて、それを少し面白くする仕掛け。

## あそびかたに載せるコア

1. どこで何をするか: 出社チャンネルの毎朝の投稿で「出社した」ボタンを押す。
2. 何が得られるか: ポイントがたまり、かたがきが上がる。目指すのはでんせつのかいしゃいん。
3. 増やし方: 早い時間、連続出社、アイテム、今週の目標。
4. その先: 転生（倍率、Lv5 なら 1.5倍）と、でんせつのしるし。

「発見」は図鑑に任せ、ここでは書かない（書くと推理の楽しみが減る）。

## 書き方

- 3つの話題（毎日 / 工夫とみんな / 長く）を、太字の見出しつきのセクションで。1つおよそ2文。カードはモバイルでは見やすいが、デスクトップでは枠が大きく見づらいので使わない。
- 落ち着いた、話しかける口調（〜よ、〜ね）。「！」は使わない。絵文字は使わない（でんせつのしるしの 🌟 は、名前の横に実際に出るので残す）。
- 太字だけ拾い読みしても流れがわかるようにする。
- ボタンやリンクは置かない（ホームのタブがすぐ上にあり、マイページは見ればわかる）。

## 文案

| カード | 本文 |
|---|---|
| **でんせつのかいしゃいんを目指そう** | 毎朝、#出社チャンネル の投稿にある **「出社した」ボタン** を押して、**ポイント** を集めよう。たまるほど **かたがき** が上がっていくよ。 |
| **もっとポイントを稼ごう** | **早い時間** の出社や **連続出社**、出社のあとに選ぶ **アイテム** で、ポイントが増えていくよ。みんなで **今週の目標** を達成すると、ボーナスもつく。 |
| **転生して、でんせつのその先へ** | Lv5 から **転生** すると、ポイントは0に戻るけど、かわりに **倍率** がかかるよ（Lv5 なら 1.5倍）。**1400pt** に届くたびに、名前の横の **でんせつのしるし** 🌟 が増えていくよ。 |
